\begin{abstract}
We introduce and formally define \emph{Constitutional Forcing}: a proposed
mechanism by which the algebraic structure of a mathematical system would
determine a governing constant, leaving no freedom in its value.

A system of depth $k$ is defined to have exactly $k$ independent
\emph{constitutional constraints}, operating on a binary configuration space of
size $2^k$, and we postulate that exactly $k$ configuration classes are
eliminated, leaving $2^k - k$ valid configurations. The governing constant is
then the configuration density
\begin{equation*}
  \thetak = \frac{2^k - k}{2^k}.
\end{equation*}
This count is a postulate, not a theorem: if a configuration is called invalid
whenever some constraint fails, there are $2^k - 1$ invalid configurations,
not $k$.

We examine three candidate instances. The Bombieri--Vinogradov level of
distribution $1/2$ is assigned depth $k = 1$, but the assignment rests on the
binary predicate ``prime or not prime'', and the same reasoning would assign
$1/2$ to any predicate. The cascade moduli $q = 3^K$ are proposed as a depth-$3$
system with conjectured level $\theta_3 = 5/8$~\cite{WakilEisenstein}; this
assignment is currently unsupported. Shannon's theorems~\cite{Shannon1948}
give the constants $H/\log|\mathcal{A}|$ and $C$, not $1/2$, and are retained
only as a proposed analogy. We state the Constitutional Forcing Conjecture:
every system with $k$ independent constitutional constraints has
$\thetak = (2^k - k)/2^k$ as its governing constant, and every depth
$k \geq 1$ is realised.

This paper is the first of a nine-paper programme (p01--p09). The remaining
eight papers develop the proposed instances, their consequences and the
cross-domain comparisons.
\end{abstract}

\section{What Constitutional Forcing Is}
%% ─────────────────────────────────────────────────────────────────────────────

\subsection{The problem this paper addresses}

Some constants in mathematics invite the question ``why this value and not
another?'' The Bombieri--Vinogradov exponent $1/2$ is an example. This paper
proposes a framework in which such a constant would be read off from the number
of independent structural constraints on the system, and it states the
framework precisely enough that each proposed instance can be checked.

We call it \emph{Constitutional Forcing}. The name is deliberate. A
constitutional constraint is one that is not imposed from outside the system but
is \emph{inherent to its constitution}---to what the system fundamentally is.
Constitutional Forcing, if it occurs, is the situation in which a system's own
constitution leaves no room for any governing constant other than the one it
has.

\subsection{Status of the proposal}

The two arithmetic candidates examined in Section~\ref{sec:instances} rest, so
far, on numerical coincidences: the Bombieri--Vinogradov exponent $1/2$ equals
$\theta_1$, and the exponent $5/8$ that Pascadi~\cite{Pascadi2025} obtained for
primes with triply-well-factorable weights to general moduli equals $\theta_3$.
A coincidence of this kind is not evidence. Section~\ref{sec:instances} checks
each candidate against the definition and records that none currently satisfies
it in full.

The purpose of this paper is therefore to fix the definitions on which the
eight companion papers rely, and to state precisely what would have to be
proved for a system to count as an instance.

\subsection{Relationship to the Shannon--Wakil Effect}

In the programme's terminology, Constitutional Forcing is the proposed
\emph{mechanism} and the Shannon--Wakil Effect~\cite{WakilShannon} the proposed
\emph{observable}: the reduction of an exponential configuration space to its
valid part. The intended relationship is:
\[
  \text{Constitutional Forcing}
  \;\xrightarrow{\text{acts on}}\;
  \text{exponential space}
  \;\xrightarrow{\text{produces}}\;
  \text{Shannon--Wakil Effect}.
\]
The present paper supplies the definitions on which~\cite{WakilShannon} relies.

\section{The Definitions}
\label{sec:definitions}
%% ─────────────────────────────────────────────────────────────────────────────

\subsection{Constitutional constraints}

\begin{definition}[Constitutional constraint]
\label{def:constitutional}
Let $S$ be a mathematical system with a binary configuration space at each
operational level. A constraint $\mathcal{C}_i$ at level $i$ is
\emph{constitutional} if it satisfies all three of the following:
\begin{enumerate}[label=\textup{(C\arabic*)}]
  \item \emph{Intrinsic.} $\mathcal{C}_i$ is forced by the irreducible algebraic
    structure of $S$---it is not a free parameter, an external imposition, or
    a modelling choice.
  \item \emph{Independent.} $\mathcal{C}_i$ is structurally independent of
    constraints at other levels: it cannot be derived from, or reduced to, a
    combination of constraints at levels $j \neq i$.
  \item \emph{Binary-eliminating.} $\mathcal{C}_i$ eliminates exactly one
    configuration class at level $i$. It does not eliminate more
    (over-constrained) or fewer (under-constrained). How the eliminated
    classes are counted in the full configuration space is fixed by
    Postulate~\ref{post:count} below.
\end{enumerate}
\end{definition}

\begin{remark}
Condition (C1) is the most important and the hardest to fake. The test is
counterfactual: \emph{could one choose a different value without changing the
algebraic structure of the system?} If yes, the constraint is not constitutional.
If no---if changing the constraint requires changing what the system fundamentally
is---then it is.
\end{remark}

\begin{remark}
Condition (C2) is what distinguishes Constitutional Forcing from ordinary
constraint satisfaction. A system with $k$ coupled constraints (each derivable
from a single underlying constraint) has effective depth $1$, not depth $k$.
An example is twin-prime admissibility modulo powers of~$3$: for $p > 3$, the
pair $(p, p+2)$ avoids divisibility by $3$ if and only if $p \equiv 2 \pmod 3$,
and every lift of this class to modulus $9$ or $27$ again avoids it, so the
``conditions'' modulo $9$ and $27$ are implied by the condition modulo $3$
(Section~\ref{sec:cascade}). Note also that $\theta_1 = \theta_2 = 1/2$
(checked in the accompanying Lean files), so the value $1/2$ alone cannot
distinguish depth $1$ from depth $2$.
\end{remark}

\subsection{Constitutional Forcing}

\begin{definition}[Constitutional Forcing]
\label{def:CF}
A system $S$ exhibits \emph{Constitutional Forcing of depth $k$} if:
\begin{enumerate}[label=\textup{(CF\arabic*)}]
  \item \emph{Configuration space.} $S$ has a binary configuration space
    $\Ck = \{0,1\}^k$ of size $2^k$ at depth $k$. Each configuration
    $c = (c_1, \ldots, c_k)$ records whether the constraint at level $i$ is
    satisfied ($c_i = 1$) or violated ($c_i = 0$).
  \item \emph{$k$ independent constitutional constraints.} $S$ has exactly
    $k$ constitutional constraints $\mathcal{C}_1, \ldots, \mathcal{C}_k$
    in the sense of Definition~\ref{def:constitutional}, one per level.
  \item \emph{Counting postulate.} Exactly $k$ configurations of $\Ck$ are
    invalid, one attributed to each $\mathcal{C}_i$
    (Postulate~\ref{post:count}), so that the valid configurations number
    $2^k - k$ and the governing constant is the configuration density
    \begin{equation}
    \label{eq:theta}
      \thetak = \frac{2^k - k}{2^k}.
    \end{equation}
  \item \emph{Uniqueness.} The governing constant of $S$ (for example, its
    level of distribution) equals $\thetak$, and it cannot be changed without
    either removing a constitutional constraint (reducing depth) or adding one
    (increasing depth).
\end{enumerate}
\end{definition}

\begin{remark}
In this revision the formula $(2^k - k)/2^k$ is part of the definition,
through the counting postulate in (CF3); it is not derived. Condition (CF4)
carries the substantive content: for a given system it asserts that the
system's governing constant equals $\thetak$ and is rigid. Verifying (CF4) for
a particular system is a mathematical claim about that system and needs its
own proof.
\end{remark}

\subsection{The counting postulate}

The February version stated the following as a theorem (the ``Counting
Theorem'') and gave a proof by induction. The proof is invalid
(Remark~\ref{rem:count}), and the statement is now a postulate.

\begin{postulate}[Counting postulate]
\label{post:count}
In a system of depth $k$, exactly $k$ configuration classes in
$\Ck = \{0,1\}^k$ are eliminated, one by each constitutional constraint.
\end{postulate}

Granting Postulate~\ref{post:count}, the valid configurations number $2^k - k$
out of $2^k$, and the configuration density is $\thetak = (2^k - k)/2^k$, as
in~\eqref{eq:theta}.

\begin{remark}[Why this is not a theorem]
\label{rem:count}
Under (CF1), $c_i = 1$ exactly when constraint $i$ holds. If a configuration is
called invalid whenever some constraint fails, then a single failing constraint
already invalidates the $2^{k-1}$ configurations with $c_i = 0$; in total
$2^k - 1$ configurations are invalid and exactly one, $(1, \ldots, 1)$, is
valid, for every $k$ (for $k = 3$: seven invalid, not three). The revised Lean
file P05 proves this count as \texttt{invalid\_count}. The withdrawn induction
overlooked that each of the $k - 1$ configurations invalid at depth $k - 1$
splits into two at depth $k$. The count $k$ is therefore an additional
assumption about which configuration classes are counted as eliminated, not a
consequence of (CF1) and (CF2).
\end{remark}

\section{Three Candidate Instances}
\label{sec:instances}
%% ─────────────────────────────────────────────────────────────────────────────

We examine three candidate instances against Definition~\ref{def:CF}. None of
them currently satisfies the definition in full; for each we record what holds
and what does not.

\subsection{Prime arithmetic: Bombieri--Vinogradov ($k = 1$)}
\label{sec:BV}

The Bombieri--Vinogradov theorem~\cite{Bombieri1965,Vinogradov1965} states
that for every $A > 0$ there is $B = B(A)$ such that
\[
  \sum_{q \leq x^{1/2}(\log x)^{-B}} \; \max_{(a,q) = 1}
  \Bigl| \psi(x;q,a) - \frac{x}{\varphi(q)} \Bigr|
  \ll_A \frac{x}{(\log x)^A}.
\]
It is a statement on average over the moduli, not one for each
$q \leq x^{1/2}$. The exponent $1/2$ is its level of distribution.

\begin{proposal}[Bombieri--Vinogradov as a depth-$1$ system]
\label{prop:BV}
It is proposed that the Bombieri--Vinogradov level of distribution $1/2$ is an
instance of Constitutional Forcing at depth $k = 1$.
\end{proposal}

\noindent\emph{Check against Definition~\ref{def:CF}.}
(CF1): Configuration space $\{0,1\}^1 = \{0,1\}$, size $2$.

(CF2): The proposed constraint is primality. A positive integer either is
prime ($c_1 = 1$) or is not ($c_1 = 0$); the constraint is intrinsic, and there
is only one. But the same reasoning applies verbatim to any predicate on the
integers (being squarefree, being a sum of two squares, \ldots), and would
assign each of them depth $1$ and constant $1/2$. As applied here, (CF2)
therefore contains nothing specific to the primes or to the
Bombieri--Vinogradov theorem.

(CF3): Under Postulate~\ref{post:count}, one configuration is invalid and one
valid, so $\theta_1 = 1/2$.

(CF4): Not established, and the justification given in the February version was
incorrect. The Generalised Riemann Hypothesis does not raise the level beyond
$1/2$: for a single modulus it gives the expected asymptotic only for
$q \leq x^{1/2-\varepsilon}$, and a level beyond $1/2$ for general moduli is
the content of the separate Elliott--Halberstam conjecture. Levels beyond $1/2$
are known unconditionally in restricted settings: $1/2 + 1/584$
(Zhang~\cite{Zhang2014}) and $1/2 + 7/300$ (Polymath~\cite{Polymath2014}) for
smooth squarefree moduli; and, for a fixed residue class and suitably
well-factorable weights, $4/7$ (Bombieri--Friedlander--Iwaniec~\cite{BFI1986}),
$3/5$ (Maynard~\cite{Maynard2020}), $66/107$ (Lichtman~\cite{Lichtman2023}) and
$5/8$ (Pascadi~\cite{Pascadi2025}). None of $4/7$, $3/5$ or $66/107$ has the
form $(2^k - k)/2^k$, so the claim of the February version that any
improvement on $1/2$ requires an increase of depth is not supported.
Pascadi's theorem concerns general moduli; it does not restrict to cascade
moduli and does not ``increase the depth''.

\subsection{Prime arithmetic: cascade moduli (proposed $k = 3$)}
\label{sec:cascade}

For cascade moduli $q = 3^K$, the companion paper~\cite{WakilEisenstein}
conjectures a level of distribution $\theta_W = 5/8$. The February version
presented this as an established depth-$3$ instance. Both the arithmetic
statement and the depth assignment are, at present, unsupported.

\begin{proposal}[Cascade moduli as a depth-$3$ system]
\label{prop:cascade}
It is proposed that primes have level of distribution $\theta_3 = 5/8$ to the
moduli $q = 3^K$, and that this is an instance of Constitutional Forcing at
depth $k = 3$. Both parts are conjectural.
\end{proposal}

\noindent\emph{Check against Definition~\ref{def:CF}.}
(CF1): Configuration space $\{0,1\}^3$, size $8$.

(CF2): The February version proposed three constraints on a twin prime pair
$(p, p+2)$ with $p > 3$, at the moduli $3$, $9$ and $27$. Only the first is a
constraint. Modulo $3$, $p \equiv 2$ is the only class for which neither $p$
nor $p + 2$ is divisible by~$3$. Modulo $9$ and $27$ nothing further is
excluded: each of the $3$ (respectively $9$) lifts of $2 \bmod 3$ keeps both $p$
and $p + 2$ prime to~$3$. The conditions modulo $9$ and $27$ are implied by the
condition modulo $3$, so (C2) fails and, by the paper's own criterion, the
depth is $1$. Nor does $\Z[\omega]$ supply three levels: since
$(3) = (1-\omega)^2$, the $(1-\omega)$-adic filtration of $\Z[\omega]/(3^K)$
has $2K$ steps, each with quotient $\mathbb{F}_3$. The ``eight configuration
classes'' were never defined.

(CF3): With one constraint, Postulate~\ref{post:count} gives $\theta_1 = 1/2$.
The value $5/8$ would require three independent constraints, and none has been
exhibited beyond the first.

(CF4): Not established. Twin-prime admissibility and the level of distribution
of primes to the moduli $3^K$ are, moreover, different objects. The arithmetic
statement itself is open in its meaningful form:
\begin{itemize}
  \item The summed statement
    \[
      \sum_{3^K \leq x^{\theta}} \max_{(a,3) = 1}
      \Bigl| \psi(x;3^K,a) - \frac{x}{\varphi(3^K)} \Bigr|
      \ll \frac{x}{(\log x)^A}
    \]
    holds for \emph{every} fixed $\theta < 1$: for $3^K > (\log x)^{A+1}$ the
    trivial bound $\ll x \log x / 3^K$ sums geometrically, and the
    Siegel--Walfisz theorem covers the $O(\log\log x)$ remaining moduli. In
    this form it carries no information about $5/8$.
  \item The per-modulus version (the expected asymptotic for
    $\psi(x;3^K,a)$ for each $3^K \leq x^{5/8-\varepsilon}$) would go beyond
    what GRH gives ($x^{1/2}$). For prime-power moduli the best known ranges are
    $3/8$ (Barban--Linnik--Tshudakov~\cite{BLT1964}), $2/5$
    (Gallagher~\cite{Gallagher1972}) and $5/12$ (Huxley), with lower bounds of
    the correct order up to $x^{0.4736}$ (Banks--Shparlinski);
    see~\cite{BaierPujahari2022} for an account.
\end{itemize}
The ``uniqueness of $5/8$'' cited in the February version (an Eisenstein
``ceiling $2/3$'' combined with cyclic-group cancellation) is withdrawn.
Pascadi's exponent $5/8$~\cite{Pascadi2025} concerns smooth numbers, and primes
with triply-well-factorable weights, in progressions to general moduli; its
numerical agreement with $\theta_3$ is a coincidence, not evidence.

\subsection{Information theory: Shannon's theorems (a proposed analogy)}
\label{sec:shannon}

The February version presented Shannon's asymptotic equipartition property
(AEP) and channel coding theorem~\cite{Shannon1948} as depth-$1$ instances. They
do not satisfy Definition~\ref{def:CF}, because their governing constants are
not $\theta_1 = 1/2$.
\begin{itemize}
  \item \emph{AEP.} For a memoryless source with alphabet $\mathcal{A}$ and
    entropy $H$ (logarithms to base $2$), the typical set has about $2^{nH}$
    of the $|\mathcal{A}|^n$ sequences of length $n$. The natural constant is
    the exponent ratio $H/\log|\mathcal{A}|$, which takes every value in
    $[0,1]$: it is $0.469$ for a Bernoulli$(0.1)$ source and $0.811$ for a
    Bernoulli$(0.25)$ source. The typical set's share of $\mathcal{A}^n$ is
    about $2^{-n(\log|\mathcal{A}| - H)}$, which tends to $0$ unless the source
    is uniform.
  \item \emph{Channel coding.} The capacity is $C = \max_{p(x)} I(X;Y)$. For a
    binary symmetric channel with crossover probability $\rho$ it is
    $1 - h(\rho)$, where $h$ is the binary entropy function; again this takes
    every value in $[0,1]$.
\end{itemize}
What the two theorems share with Definition~\ref{def:CF} is a binary split
(typical or atypical; rate achievable or not). As with primality in
Section~\ref{sec:BV}, a binary split by itself would assign depth $1$ to any
predicate. We therefore retain the comparison only as a proposed analogy: in
both settings a condition intrinsic to the system singles out part of an
exponential space, and a constant fixed by the system governs its size.
Whether the analogy can be sharpened into an instance of
Definition~\ref{def:CF} is open; as it stands, the constants
$H/\log|\mathcal{A}|$ and $C$ do not equal $\theta_1$.

\section{Non-Instances and Falsifiability}
\label{sec:noninstances}
%% ─────────────────────────────────────────────────────────────────────────────

A framework that cannot be wrong is not mathematics. For Constitutional
Forcing to make predictions, the depth $k$ of a system---its constraints, with
(C2) checked---must be fixed before its governing constant is compared with
$\thetak$. Constitutional Forcing at depth $k$ requires \emph{genuinely}
independent constraints, in the sense of (C2), not merely the appearance of
independence; Section~\ref{sec:cascade} gives an example where apparent
independence fails. The February version did not meet this standard, and its
proposed non-instance did not test the framework.

\begin{remark}[Sophie Germain pairs]
\label{rem:sophie}
The February version treated Sophie Germain pairs $(p, 2p+1)$ as a
``non-instance'' of depth $2$ with effective depth $1$, on the ground that
``$2p+1$ is odd'' follows from ``$p$ is odd''. That is no constraint at all:
$2p + 1$ is odd for every integer $p$. The genuine local coupling is
modulo~$3$: for $p > 3$, the conditions $3 \nmid p$ and $3 \nmid 2p+1$ together
force $p \equiv 2 \pmod 3$, the same single condition as for twin primes. Since
$\theta_1 = \theta_2 = 1/2$, the example cannot discriminate between depths $1$
and $2$ and is not a falsification test. Moreover, a ``level of distribution of
Sophie Germain pairs'' is not a defined notion, and no finite computation can
confirm an asymptotic level, so the claimed computational confirmation is
withdrawn. The accompanying Lean files check $\theta_1 = \theta_2$ and the
mod-$3$ fact.
\end{remark}

\section{The Constitutional Forcing Conjecture}
\label{sec:conjecture}
%% ─────────────────────────────────────────────────────────────────────────────

\begin{conjecture}[Constitutional Forcing Conjecture]
\label{conj:CF}
Let $S$ be a system exhibiting Constitutional Forcing of depth $k$ in the sense
of Definition~\ref{def:CF}. Then the governing constant of $S$ is uniquely
forced to be
\[
  \thetak = \frac{2^k - k}{2^k},
\]
and this value is achievable: there exist systems exhibiting Constitutional
Forcing at every depth $k \geq 1$.
\end{conjecture}

\begin{remark}
Conjecture~\ref{conj:CF} has two parts. Under Definition~\ref{def:CF} the value
$\thetak$ is built into (CF3) through Postulate~\ref{post:count}, so the
\emph{uniqueness} part holds by definition and carries no independent content.
The substantive content is the \emph{achievability} part: for each $k$, a
system must be exhibited whose $k$ constraints are fixed in advance and satisfy
(C1)--(C3), and whose governing constant is proved to equal $\thetak$, as (CF4)
requires. No depth is currently realised in this sense: the $k = 1$ candidates
of Section~\ref{sec:instances} rest on binary splits that would assign $1/2$ to
any predicate, and the $k = 3$ candidate is unsupported. The February version
singled out $k = 4$, with governing constant $3/4$, as the first open case; in
fact every depth, including $k = 1$, is open in this sense.
Table~\ref{tab:theta} is the programme's prediction set, and it becomes
falsifiable only when $k$ is fixed for a system before its constant is known.
\end{remark}

\begin{remark}
The companion paper~\cite{WakilShannon} discusses a version of this conjecture
in the terminology of the Shannon--Wakil Effect. The February version of this
remark attributed to~\cite{WakilShannon} a category of Shannon--Wakil systems
and a functor to $(0,1)$; no such construction appears there, and none is
claimed here.
\end{remark}

\section{What Constitutional Forcing Is Not}
\label{sec:not}
%% ─────────────────────────────────────────────────────────────────────────────

\subsection{Not, at present, more than an analogy across domains}

The February version claimed that Constitutional Forcing is not an analogy
between number theory and information theory but a common, causal mechanism
that both instantiate. That claim is withdrawn. Section~\ref{sec:shannon}
shows that the information-theoretic constants are not $\theta_1$; the
comparison is a proposed analogy, and no causal link is claimed.

\subsection{Numerology, and how to avoid it}

The formula $\thetak = (2^k-k)/2^k$ is not derived from the definitions: it is
the counting postulate (Postulate~\ref{post:count}), and the February claim
that ``the formula is a theorem, not a fit'' is withdrawn. Whether the
framework is more than numerology therefore depends on whether $k$ can be fixed
for a system independently of the constant to be explained. The risk is
concrete: if $k$ or the size of the configuration space may be chosen after the
target value is known, the formula can be made to match many constants, and
since $\theta_1 = \theta_2 = 1/2$ the value $1/2$ cannot identify the depth at
all. A candidate instance should therefore
(i) use the configuration space $\{0,1\}^k$;
(ii) fix $k$ and the constraints, with (C2) checked, before any comparison with
a known constant; and
(iii) prove (CF4) for the system.
None of the candidates in Section~\ref{sec:instances} meets all three
conditions at present, and the Sophie Germain example (Remark~\ref{rem:sophie})
is not a test.

\subsection{Not a claim of isomorphism}

We do not claim that prime arithmetic and information theory are isomorphic, or
that there is a functor between them as mathematical objects. The February
version claimed that both exhibit Constitutional Forcing; in this revision we
claim only a proposed analogy (Section~\ref{sec:shannon}). Two physical systems
that both obey Hamiltonian dynamics share a structural description without
being isomorphic; here, even the shared description is not yet established.
