## CRITICAL

### P05-C1. The Counting Theorem contradicts the paper's own definitions: "valid" gives exactly 1 configuration, not 2^k − k (Fact 2 propagates)
- **Severity:** CRITICAL. **Status:** VERIFIED.
- **Where:** p05.tex:242-247 (Def 3.1), 270-295 (Thm 3.4), 297-308 (Prop 3.5), 359-362 (proof of Prop 4.1), 75-78 (abstract), 152-155 ("[Proved]"); Lean lines 30 and 33.
- **Quote:** "records whether the constitutional constraint is satisfied ($c_i = 1$) or fails ($c_i = 0$)"; "exactly $k$ configurations in $\mathcal{C}_k$ are invalid"; and at line 361-362: "Configuration density counts binary vectors in $\{0,1\}^k$ with all coordinates equal to $1$."
- **What is wrong:** By Def 3.1, a configuration is valid only if every c_i = 1. Exactly one vector in {0,1}^k has that property. The paper says so itself at line 361-362. So there is 1 valid configuration and 2^k − 1 invalid ones, which contradicts Thm 3.4 and Prop 3.5. One failing coordinate invalidates 2^{k−1} vectors, so Def 3.2(c) ("eliminates exactly one configuration class") cannot hold.
- **The induction is miscounted.** Lines 288-289 say the k−1 invalid configurations "remain invalid", but each of them splits into two, giving 2(k−1). Taking the inductive hypothesis at face value, the level-k failure applies to all 2^{k−1}−(k−1) previously valid configurations, not to one.
  - Counted honestly: I_k = 2·I_{k−1} + 1 = 2^k − 1.
  - Counted with the paper's own inductive hypothesis: 2(k−1) + 2^{k−1} − (k−1) = 3, 6, 11, 20, … for k = 2, 3, 4, 5. That is never k.
- **Lean:** the Lean definitions `isValid := ∀ i, c i = true` and `isInvalid := ∃ i, c i = false` also give 1 valid and 2^k−1 invalid configurations.
- **Evidence:** `c1_counting.py` enumerates k = 1..7: valid = 1 and invalid = 1, 3, 7, 15, 31, 63, 127. Exactly k vectors have a single failing coordinate, which is all the Lean file proves.
- **Fix:** Withdraw Theorem 3.4 and Prop 3.5 as theorems. State 2^k − k as a stipulated definition with no derivation, or define a configuration model in which the count actually comes out to 2^k − k. No such model is given here or in p01.

### P05-C2. The geometric pillar's exponents do not give 5/8, and "improves 2/3 to 5/8" is a decrease
- **Severity:** CRITICAL. **Status:** VERIFIED.
- **Where:** p05.tex:378-382, 442-448, 450 (section title), 467-475, 498-500.
- **Quote:** "Part II: Cyclic group structure improves $2/3$ to $5/8$"; "$E_{II} \ll x^{1/2} Q^{1/2} \cdot Q^{3/16 + \varepsilon}$. Power-saving requires $Q \ll x^{5/8 - \varepsilon}$"; "each contributing exactly half the improvement over the Weil bound".
- **What is wrong:**
  1. 5/8 = 0.625 is less than 2/3 = 0.667. A sharper exponential-sum bound can only widen the admissible range of Q, never shrink it.
  2. The paper's own arithmetic does not give 5/8. From x^{1/2}Q^{1/2+3/16} = x^{1/2}Q^{11/16} ≪ x^{1−δ}, the range is Q ≪ x^{8/11} ≈ x^{0.727}. Getting 5/8 would need a Q-exponent of 4/5, which is a weaker bound than Part I's 3/4.
  3. Part I's "power-saving when Q ≪ x^{2/3}" is a range the method achieves (a lower bound on the level), but line 447-448 calls it a "ceiling θ ≤ 2/3". If Part I held, it would already give more than 5/8.
  4. "Each contributing exactly half the improvement": going from 1/2 to 5/8 is an improvement of 1/8, so each half would be 1/16. But Part I alone is said to reach 2/3, an improvement of 1/6.
- **Evidence:** `c2_exponents.py` (sympy). Part I threshold = 2/3; Part II threshold = 8/11; the Q-exponent needed for 5/8 is 4/5.
- **Fix:** Remove the claim that 5/8 is derived. As written, the exponents are not mutually consistent and do not produce 5/8.

### P05-C3. Proposition 5.6's Kloosterman bound Q^{3/8} is false: Weil's q^{1/2} is sharp for q = 3^K
- **Severity:** CRITICAL. **Status:** VERIFIED.
- **Where:** p05.tex:467-486.
- **Quote:** "$\sum_{3^K \leq Q} |S(a, b; 3^K)| \ll Q^{3/8 + \varepsilon}$ … yielding $|S(a, b; 3^K)| \ll (3^K)^{3/8+\varepsilon}$".
- **What is wrong:** For prime-power moduli, Kloosterman sums can be evaluated explicitly (Salié-type evaluation), and they have size about 2q^{1/2} whenever they are nonzero. A pointwise bound of q^{3/8} is impossible. The mean-square identity Σ_{a mod q} |S(a,1;q)|² = q·φ(q) forces the root-mean-square value of |S| to be about q^{1/2}.
- **Evidence:** `c3_kloosterman.py`:
  - |S(1,1;3^K)| = 18, 54, 162, 486 for K = 4, 6, 8, 10. That is exactly 2·3^{K/2}.
  - max_b |S(1,b;3^K)| / q^{3/8} = 1.3, 2.5, 3.0, 3.5, 4.0, 4.6, 5.2, 6.0, 6.9, 7.9 for K = 1..10. The ratio grows like q^{1/8}.
  - The partial sums Σ_{3^j ≤ Q} |S(1,1;3^j)| reach 728.8 at Q = 3^10, against Q^{3/8} = 61.5.
  - The mean-square identity was checked for K = 3, 5, 6.
- **The proof sketch is a non-sequitur.** Subconvexity bounds for L(s,χ) do not bound individual Kloosterman sums. Watt's theorem is about ζ(s) (see P05-M6).
- **If "improving convexity by 1/8" means L(1/2,χ) ≪ q^{1/8}:** that would be far beyond the best known bound for prime-power moduli. Milićević (Compositio 2016) gets exponent ≈ 0.1645, just under Weyl's 1/6.
- **Fix:** Delete Prop 5.6. The Weil bound 2q^{1/2} is optimal for q = 3^K.

### P05-C4. Theorem 5.7 as stated is trivially true for every exponent up to 1, so "5/8 … and nothing else" is false. The meaningful version would exceed GRH (Fact 5 propagates)
- **Severity:** CRITICAL. **Status:** VERIFIED.
- **Where:** p05.tex:488-510; also 96-98, 162-164, 378-381 ("the analytic level of distribution is exactly θ = 5/8").
- **Quote:** "$\sum_{K\ge1,\ 3^K \leq x^{5/8-\varepsilon}} \max_{a} |\psi(x;3^K,a) - x/\varphi(3^K)| \ll x/(\log x)^A$ … The value $5/8$ is uniquely forced … together they force $5/8$ and nothing else."
- **Why the theorem is trivial:** the sum has only O(log x) moduli, and Σ 1/3^K converges. Split the range of K:
  - Moduli 3^K ≤ (log x)^{A+2}: Siegel–Walfisz gives O(x·exp(−c√log x)) for each of the O(log log x) terms.
  - Moduli 3^K > (log x)^{A+2}: the trivial bound |ψ(x;q,a) − x/φ(q)| ≤ (2.5x/q + 1)·log x sums to ≪ x/(log x)^{A+1}.
  - So the stated bound holds with 5/8 replaced by any exponent ≤ 1, with no use of Eisenstein integers, Kloosterman sums, Watt or W3.
- **Numerics (`c5_thm57.py`, x = 10^7):**
  - The sum is 8396 at θ = 1/2, 9166 at θ = 5/8, 9457 at θ = 3/4 and 9613 at θ = 1 (about 10^{−3}·x).
  - Moving from θ = 5/8 to θ = 1 adds less than 5%. The exponent is irrelevant to the statement.
- **The non-trivial version:** an asymptotic for each single modulus, ψ(x;3^K,a) ~ x/φ(3^K) for 3^K ≤ x^{5/8}, would exceed GRH. GRH gives only x^{1/2−ε} for a single modulus. The known prime-power results are Barban–Linnik–Tshudakov 3/8, Gallagher 2/5, Huxley 5/12 and Banks–Shparlinski about 0.47.
  - Numerically, at q = 3^9 ≈ x^{0.613} the maximum relative error is 38%, and at q ≈ x^{0.75} it is 133%.
- **Other problems:**
  - The proof (lines 504-509) decomposes "w(d) = α(d1)β(d2)γ(d3)", but the theorem's statement contains no sieve weights.
  - "Level of distribution" over the O(log x) moduli {3^K} is not the standard notion, which concerns all q ≤ x^θ or a sieve-relevant family. The paper concedes at lines 604-607 that this family cannot serve GPY.
- **Fix:** Either state the trivial result honestly (it holds for every exponent below 1), or state the single-modulus asymptotic. The latter is an open problem beyond GRH and has not been proved.

### P05-C5. The "unification" of BV and Pascadi is a misattribution, and known levels do not follow θ_k (Facts 4 and 7 propagate)
- **Severity:** CRITICAL. **Status:** VERIFIED.
- **Where:** p05.tex:85-88, 116-117, 125-126, 522-536 (Thm 6.1), 572-573 (Table 2), 637 (Table 3); HTML Table 1.
- **Quote:** "The formula unifies the classical Bombieri--Vinogradov barrier ($\theta_1=1/2$, $k=1$) and Pascadi's breakthrough ($\theta_3 = 5/8$, $k=3$ …) as special cases of the same principle"; "Pascadi 2025; Thm. 5.7 … Two independent proofs".
- **What Pascadi actually proved:** arXiv:2505.00653 shows that smooth numbers, and primes weighted with triply-well-factorable weights, are equidistributed to general moduli up to x^{5/8−o(1)}.
  - This is a weighted sum with a fixed residue class and no absolute values.
  - The exponent comes from new large-sieve inequalities for exceptional Maass forms together with Kim–Sarnak, not from counting configurations.
  - It is not about the moduli 3^K, and it is not the statement of Thm 5.7 (absolute values, max over a, moduli 3^K). The "two proofs" therefore prove different statements.
- **Known levels contradict θ_k:**
  - The same "k = 3" weight class (triply well-factorable) gives 3/5 (Maynard 2020), 66/107 (Lichtman) and 5/8 (Pascadi). The exponent depends on the analytic input, not on "3".
  - Well-factorable weights, the natural "k = 2", give 4/7 (Bombieri–Friedlander–Iwaniec 1986, BFI). Linear-sieve weights give 7/12 (Maynard) and 10/17 (Lichtman's modified sieve). All of these exceed θ_2 = 1/2.
  - Zhang's 1/2 + 1/584 and Polymath's 1/2 + 7/300 are also not θ_k values.
  - Every one of these lies strictly between θ_2 = 1/2 and θ_3 = 5/8, so the "universal formula for sieve levels" misses all of them.
- **On BV:** Bombieri–Vinogradov's 1/2 comes from the large sieve (N + Q²). It has no constraint count, and GRH does not raise it.
- **Fix:** Drop the unification claim. Cite Pascadi accurately, and describe 5/8 as a spectral-method exponent unrelated to θ_k.

### P05-C6. "θ_5 = 27/32 together with GPY implies infinitely many twin primes" is false
- **Severity:** CRITICAL. **Status:** VERIFIED (standard literature).
- **Where:** p05.tex:167-168, 596-601, 603-607, 639; HTML line 208 ("If this can be established … twin prime infinitude follows. The formula already knows the answer.").
- **Quote:** "$\theta_5 = 27/32$ holds analytically. Combined with the Goldston--Pintz--Yıldırım theorem, this would imply the existence of infinitely many twin primes."
- **What is wrong:** GPY turns a level θ > 1/2 into bounded gaps, not gap 2.
  - Even the full Elliott–Halberstam conjecture (θ = 1 − ε) gives only gaps ≤ 16 (GPY) or ≤ 12 (Maynard 2015).
  - Generalised EH gives ≤ 6 (Polymath8b), and the parity barrier blocks gap 2 for these sieve methods.
  - A level of 27/32 ≈ 0.84 cannot give twin primes. It would only improve the bounded-gap constant, and bounded gaps are already unconditional (Zhang/Maynard).
- **Internal inconsistency:** twin primes are assigned k = 3 (Example 3.3, Table 3), yet the "twin prime threshold" is placed at k = 5 for an unspecified "5-element constellation".
- **Fix:** Remove the conjecture's implication and the related statements in the HTML.

### P05-C7. The "empirical" column (0.624 ± 0.002, 0.749 ± 0.003, 0.843 ± 0.004) is undefined, cannot be reproduced and cannot be measured at the stated precision
- **Severity:** CRITICAL. **Status:** VERIFIED.
- **Where:** p05.tex:566-581.
- **Quote:** "$4$ & $3/4$ & --- & $0.749 \pm 0.003$ & Computational … Empirical measurements are from prime distribution over $[2, 10^6]$ in cascade moduli; all $p > 0.05$ against the formula predictions."
- **What is wrong:**
  1. No statistic, method, code or data is given. A search of the whole repository for 0.749, 0.843 or 0.624 finds only this table.
  2. The data described ("prime distribution over [2,10^6] in cascade moduli") does not depend on k. A single dataset cannot produce three different k-dependent "levels".
  3. The k = 4 and k = 5 objects are undefined: Table 3 says only "4-element constellation" and "5-element constellation", and the HTML says "Unknown prime constellation with 4 constraints". Something unspecified cannot be measured.
  4. A level of distribution is an asymptotic exponent. With x = 10^6, the moduli 3^K ≤ x give log_x(q) only on a grid of step log 3/log 10^6 = 0.0795 (values …0.557, 0.636, 0.716, 0.795, 0.875…).
     - The grid points nearest 0.624, 0.749 and 0.843 are 0.636, 0.716 and 0.875. These are 0.012, 0.033 and 0.032 away, which is 6 to 11 times the quoted error bars.
     - Precision of ±0.002 is impossible.
  5. Natural statistics, such as the largest 3^K whose maximum relative error is below a threshold c, give 0.318, 0.398, 0.477, 0.557 or 0.636 for c = 0.05, 0.1, 0.2, 0.5 or 1. The answer is set by the arbitrary c. A log-log regression crossing point gives 0.725. None reproduces the table.
  6. "p > 0.05" (failing to reject) is not validation, and no test is named.
- **Observation (not a finding of fabrication):** the three entries lie 0.5σ, 0.33σ and 0.19σ below the predictions.
- **Evidence:** `c6_empirical.py`.
- **Fix:** Delete the column, or publish an exact definition, the code, and a k-dependent dataset.

### P05-C8. The twin primes' "three nested levels" (moduli 3, 9, 27) are not independent and break the paper's own Def 3.2(b) (Fact 3 propagates)
- **Severity:** CRITICAL. **Status:** VERIFIED.
- **Where:** p05.tex:254 (Def 3.2(b)), 259-266 (Example 3.3), 137-141, 637.
- **Quote:** "it is CRT-independent of constraints at other levels"; "The three nested levels use moduli $3, 9, 27$, giving $k = 3$".
- **What is wrong:**
  - 3, 9 and 27 are not pairwise coprime, so the Chinese Remainder Theorem says nothing about independence. Conditions mod 9 and mod 27 refine the mod-3 condition and do not stand apart from it.
  - For twin primes p > 3, the only constraint is p ≡ 2 (mod 3). The levels mod 9 and mod 27 add nothing. By the programme's own criterion the depth is 1, so θ = θ_1 = 1/2, and the identification of twin primes with k = 3 collapses.
- **Evidence:** `c4_twins.py` uses the 58,979 twin pairs with p ≤ 10^7.
  - mod 9: p ≡ 2, 5, 8 with frequencies 0.3336, 0.3338, 0.3326.
  - mod 27: all nine classes ≡ 2 (mod 3) occur, each with frequency between 0.109 and 0.113.
- **Fix:** Withdraw the k = 3 assignment for twin primes.

## MAJOR

### P05-M1. Proposition 2.3 (Khayyam's triangle as the "combinatorial origin") is unproved and contradicted by computation
- **Severity:** MAJOR. **Status:** VERIFIED.
- **Where:** p05.tex:88-90, 159-161 ("[Proved]"), 203-225.
- **Quote:** "this structure partitions configurations of a $K$-level cascade sieve into those compatible … (exactly $2^K - K$ valid configurations)".
- **What is wrong:**
  - The proof never links Lucas's theorem to 2^K − K. Its second paragraph simply restates Thm 3.4 by forward reference, which is circular.
  - The actual Sierpiński counts are different. Rows 0..3^K−1 contain 6^K nonzero entries, a density of 2^{K+1}/(3^K+1). That density tends to 0, whereas θ_K tends to 1.
  - At K = 3 the density is exactly 216/378 = 4/7 ≈ 0.571. This is essentially the value that §4 dismisses as "incorrect".
  - The proposition uses q = 3^K with K levels, so by its own statement moduli 3^K up to x^{5/8} (K ~ log x) would have density (2^K−K)/2^K → 1. That contradicts "θ = 5/8 for cascade moduli". The paper conflates sieve depth k = 3 with the modulus exponent K.
- **Evidence:** `c8_khayyam.py`.
- **Fix:** Remove the proposition or downgrade it to a heuristic remark. Do not label it "[Proved]".

### P05-M2. Proposition 4.1 (pattern vs configuration density): wrong formula, wrong "12%", false large-sieve claim
- **Severity:** MAJOR. **Status:** VERIFIED.
- **Where:** p05.tex:91-92, 156-158, 335-371.
- **Quote:** "This $12\%$ discrepancy"; "$\rho^{pattern}_3=\prod_{i=1}^3(1-3^{-i})\approx0.571$"; "via an Euler product over small primes"; "Dirichlet characters are indexed by constraint-satisfaction classes".
- **What is wrong:**
  1. The figure is not 12%. 0.625/0.5706 − 1 = 9.5%, and 1 − 0.5706/0.625 = 8.7%.
  2. ∏_{i≤3}(1−3^{−i}) = 416/729 = |GL_3(F_3)|/3^9 (the probability that a 3×3 matrix over F_3 is invertible). It is not a residue-class density. The actual densities mod 27 are 18/27 (p coprime to 3) and 9/27 (twin-admissible).
  3. It is a product over powers of one prime, not "an Euler product over small primes".
  4. The Montgomery–Vaughan large sieve sums over all primitive characters mod q for every q ≤ Q. There is no "compatible" subfamily, and characters are indexed by the dual group of (Z/qZ)^*, not by binary classes.
  5. The "proof" ends with "This is why θ_3 = 0.625 matches", which is circular.
- **Evidence:** `c1_counting.py`; GL_3 check run inline.
- **Fix:** Delete the proposition and the "12%" claims, or define the pattern density properly and prove a statement about the large sieve.

### P05-M3. Nothing in the paper comes from Ramanujan, and the "Ramanujan principle" is invented
- **Severity:** MAJOR. **Status:** VERIFIED.
- **Where:** title (46-47), keywords (56), 130-144, 677-681.
- **Quote:** "Ramanujan observed that certain numbers---notably $24$ in the Dedekind eta function and partition congruences mod $5, 7, 11$---force exact asymptotic formulas through their structural properties alone".
- **What is wrong:**
  - No result of Ramanujan is used anywhere in the paper, and the bibliography contains no Ramanujan reference.
  - The partition congruences p(5n+4) ≡ 0 (mod 5) and so on are congruences, not asymptotic formulas.
  - The asymptotic p(n) ~ e^{π√(2n/3)}/(4√3·n) is Hardy–Ramanujan (1918), via the circle method and the modularity of η.
  - η and its q^{1/24} factor are due to Dedekind (1877).
  - No "principle that structural properties of certain numbers force exact arithmetic formulas" appears in Ramanujan's work.
- **Irony:** the real 5/8 depends on progress towards Selberg's eigenvalue conjecture (Kim–Sarnak 7/64), the archimedean analogue of Ramanujan–Petersson. The paper does not mention it.
- **Also:** "the configuration space has $2^3 = 8$ dimensions" (line 139-140) is wrong. {0,1}^3 has 8 points and dimension 3.
- **Fix:** Remove the Ramanujan attribution from the title and text, or cite a specific Ramanujan result that is actually used.

### P05-M4. The "three-level" filtration and the "triply-well-factorable" corollary are mislabelled and mis-defined
- **Severity:** MAJOR. **Status:** VERIFIED.
- **Where:** p05.tex:79-82, 416-440.
- **Quote:** "Three-level filtration … $\supset (1-\omega)^{2K}$"; "$w(d) = \alpha(d_1)\beta(d_2)\gamma(d_3)$".
- **What is wrong:**
  - The displayed filtration has 2K steps, not three. Nothing in it singles out three scales.
  - The Corollary is not deduced from the Proposition; no proof is given.
  - "Triply well-factorable" (Maynard, Lichtman, Pascadi) means that for every factorisation D = Q1Q2Q3 the weight λ can be written as a Dirichlet convolution α*β*γ with supports in [1,Q_i]. The paper's version is a pointwise product w(d) = α(d1)β(d2)γ(d3), on a factorisation d = 3^{j1}3^{j2}3^{j3} that is not unique (there are C(j+2,2) of them), so it is not "canonical".
  - Weights supported on powers of 3 are not sieve weights. Sieve weights live on squarefree d whose prime factors are below z, and sieving by the prime 3 alone detects nothing about primality.
- **Fix:** Remove the corollary, or define triple well-factorability correctly and prove it.

### P05-M5. The "cyclic structure" mechanism does not single out 3 or k = 3
- **Severity:** MAJOR. **Status:** VERIFIED.
- **Where:** p05.tex:452-465, 478-486.
- **Quote:** "The product structure obstructs the uniform character cancellation that a single cyclic group enables."
- **What is wrong:**
  - (Z/p^K)^* is cyclic for every odd prime power. If the argument were valid it would apply equally to 5^K, 7^K and so on, so it cannot "force" anything specific to 3 or to Z[ω].
  - The claim about squarefree moduli is unsupported. Weil's bound holds there too, and the level-beyond-1/2 results (BFI, Maynard, Pascadi) work with general or smooth moduli, not cyclic ones.
  - Prime-power Kloosterman sums do not cancel better than Weil (see C3).
- **Fix:** Delete the claim.

### P05-M6. Watt's theorem is misdescribed, and the "Watt conditions" in p05 differ from those "verified" in p04
- **Severity:** MAJOR. **Status:** VERIFIED for the nature of Watt's theorem; SUSPECT for the precise hypotheses of Watt's Theorem 1, since the paper itself was not accessible.
- **Where:** p05.tex:478-486, 646-671, 724-727.
- **Quote:** "Watt's theorem applies to characters of cyclic groups. \checkmark"; "support in $[1, Q^{1/3}]$ per factor, with $|\alpha|,\ldots \leq \tau(n)^C$".
- **What is wrong:**
  - Watt (J. Number Theory 53, 1995) proves a mean value for the Riemann zeta function in the t-aspect: ∫_0^T |ζ(1/2+it)|^4 |Σ_{m≤M} a_m m^{−it}|² dt ≪ T^{1+ε} M(1 + M²T^{−1/2}) max|a_m|². This is how Ivić and Bettin–Chandee–Radziwiłł quote it.
  - The theorem involves no Dirichlet characters mod q, no cyclic groups and no triple sieve weights, so the conditions W1 and W2 as stated in p05 are not Watt's hypotheses.
  - p05 line 485 defers to p04 Appendix A, but p04 "verifies" different conditions: W1 "M ≤ q", W2 "MR ≤ q²", and W3 "θ_f ≤ 7/32". The two papers list different hypotheses for the same theorem.
- **Fix:** Cite Watt for what it proves, or remove it.

### P05-M7. Condition W3 (no Siegel zeros mod 3^K) is trivial, and the CM argument is irrelevant (Fact 6 propagates)
- **Severity:** MAJOR. **Status:** VERIFIED.
- **Where:** p05.tex:96-98, 162-164, 509, 664-671.
- **Quote:** "the existence of a Siegel zero for a character of $(\Z/3^K\Z)^*$ would contradict the known zero-free region for $L$-functions of CM fields."
- **What is wrong:**
  - (Z/3^K)^* is cyclic of even order, so it has exactly one non-principal real character. That character is (·/3), induced from modulus 3.
  - For K ≥ 2 there is no primitive real character, so there is nothing to exclude. For K = 1 there is a single fixed L-function, with L(σ, χ_{−3}) ≥ 0.336 on (0,1) and L(1, χ_{−3}) = π/(3√3).
  - Siegel zeros are an issue for families with q → ∞. W3 is also unnecessary for Thm 5.7 (see C4).
  - The general claim that CM zero-free regions exclude Siegel zeros is not a known theorem in that generality (SUSPECT as phrased).
- **Evidence:** `c7_w3.py` checks K = 1..6.
- **Fix:** Replace W3 with the one-line remark above, and stop presenting it as a substantive condition.

- **Severity:** MAJOR. **Status:** VERIFIED.
